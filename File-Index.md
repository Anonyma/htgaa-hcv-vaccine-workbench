## Quick Start for Reviewers

Open these three files first:

1. `HCV_Workbench_Reviewer_Notebook.ipynb` — the Colab-first reproducibility path
2. `docs/HTGAA-2026-Final-Project.md` — the full formal submission with scorecard, design rationale, and nomination
3. `data/design-scorecard.tsv` — the transparent 100-point rubric showing how each design was scored

After that, `docs/How-to-Run.md` and `docs/Verification-Guide.md` provide re-execution and independent-check instructions.
